# Dynamics of Spatially Embedded Neuronal Networks with Distance-Dependent Synaptic Delays

This repository contains the computational codes developed to investigate the dynamics of spatially embedded neuronal networks with distance-dependent synaptic delays.

## Associated Publication

**Title:** Dynamics of spatially embedded neuronal networks with distance-dependent synaptic delays

**Authors:** Cristina Jordi and Bruno R. R. Boaretto.

**Journal:** *Philosophical Transactions of the Royal Society B: Biological Sciences* (The Royal Society).

**Status:** Under review since 9 November 2026.

## Codes

The repository contains two main components:

### 1. Spatial neuronal culture generation (Python 3)

The script `generatue_culture_network.py` generates spatially embedded neuronal cultures within a circular region. Neuronal positions are randomly distributed and sorted from left to right. Axonal growth is modelled through stochastic trajectories, while dendritic regions are represented by circular areas.

Directed synaptic connections are established when an axon intersects the dendritic region of another neuron, with a connection probability of 10%.

**Usage:**

```bash
python3 generatue_culture_network.py N D seed
```

where `N` is the number of neurons, `D` is the culture diameter in mm, and `seed` is the random seed.

### 2. Neuronal network simulations (C)

The C code implements the numerical integration of spatially embedded Hodgkin–Huxley neuronal networks with distance-dependent synaptic delays. It reads the neuronal positions and connectivity generated by the Python script and calculates transmission delays according to the Euclidean distance between connected neurons and the signal propagation velocity.

The code investigates the effects of coupling strength and propagation velocity on collective neuronal dynamics, quantifying synchronisation through the Kuramoto order parameter and its higher harmonics, as well as additional firing statistics.

## Requirements

**Python 3:** NumPy, Matplotlib, NetworkX.

**C:** GCC compiler and the standard mathematical library (`libm`).
