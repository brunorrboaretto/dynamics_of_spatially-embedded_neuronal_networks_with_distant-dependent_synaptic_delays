# Dynamics of Spatially Embedded Neuronal Networks with Distance-Dependent Synaptic Delays

This repository contains the computational codes developed for the study of dynamics in spatially embedded neuronal networks with distance-dependent synaptic delays.

The repository includes Python scripts for generating spatial neuronal cultures and analysing their collective dynamics. In particular, the analysis tools quantify neuronal synchronisation using the Kuramoto order parameter and distance-dependent pairwise phase correlations.

The codes are intended to support the numerical analyses and reproduce the results presented in the associated research article.
